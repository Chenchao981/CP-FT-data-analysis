## 2. 已完成

### 2.1 按用户任务重组分析入口

- 将六个技术页面整理为五个中文入口：分析总览、参数图表、晶圆空间、质量管控、报告与数据。

- CP 显示晶圆空间；FT 自动隐藏该入口，避免展示不适用功能。
- 批次、晶圆、参数、测试结果、数据源、测试机、程序版本和测试条件统一使用业务中文。
- Context Hash、Filter Hash、合同版本和规则版本移入“高级信息”，普通使用路径不再被技术字段占据。

### 2.2 复用 PAT 结果视图

- 新增统一 PAT 结果组件，集中展示参数/分组数、有效数据数、异常数、已计算限值数。
- 使用 ECharts 展示 PAT 下限、中位数和上限，并保留可横向浏览的统计表。
- 正式数据的 PAT 质量分析复用该组件。
- 快速分析成功记录可以直接展开，在任务列表内查看 PAT 参数图表和统计表，不必先下载 Excel 才能确认结果。

### 2.3 减少规则字段干扰

- 普通页面优先自动复用当前 Dataset Context 中唯一匹配的既有规则身份。
- 缺失或存在多个候选时保持未选择，不猜测规则。
- 完整词匹配防止把 `SPATIAL` 误识别为 `PAT`。
- 规则编号和版本保留在折叠的高级设置内，供管理员调试；执行时仍由服务器重新检查审批、激活和适用范围。
