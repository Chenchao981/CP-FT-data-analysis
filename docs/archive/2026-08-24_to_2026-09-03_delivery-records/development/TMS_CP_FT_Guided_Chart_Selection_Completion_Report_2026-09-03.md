# TMS CP/FT 引导式图表选择完成报告（2026-09-03）

## 本次目标

参考历史 `VDMOS_Tool_v8.9.html` 的多选、全选和显式绘图交互，在现有 React + ECharts + 服务端分析架构内实现 CP/FT 数据分析入口，不将历史 HTML 中的解析或统计逻辑复制到前端。

## 已完成

- CP 和 FT 页面新增「选择数据并绘制图表」引导区，顺序为：数据来源 → 产品名称 → 多批次 → 多参数 → 图形 → 绘制。
- 数据来源按后端真实 `source_channel` 区分：
  - `WEB`：当前用户的本机上传；
  - `SOURCE_CATALOG`：服务器目录或自动清洗链路。
- 产品与批次级联；批次可多选，一次最多 8 个 Dataset。同一 Lot 有多次历史处理时只选最新结果，避免将非 Current Published 版本混入同一 Context。
- 只有选定数据集/批次后才请求参数清单。
- 参数使用复选框，支持「全选」和「清空」；一次显式分析上限由 5 扩展到 20 个参数。
- 图形可多选：描述统计、箱线图、直方图、正态拟合、能力分析、散点图、趋势图、相关性矩阵。
- 需要精确规则但当前 Dataset 未配置规则的图形直接置灰，避免事后失败。
- 仅在点击「绘制所选图表」后进入统一分析页并自动执行本次图表请求。
- 散点/趋势首屏取已选前两个参数作为 X/Y，限制 500 点；进入分析页后可增加 Y 参数与采样点数。
- CP 页已移除「最近清洗结果图表」及「查看最新图表」；个人驾驶舱继续承担最近良率趋势展示。

## 已知边界

- CP/FT 入口面向「最近数据」，候选项来自当前服务端结果页；更大的历史范围仍从「历史正式数据」进入。
- 当前测试库 CP 最近数据均为 `WEB` 上传，所以「服务器目录 / 自动清洗」计数为 0；接入 `SOURCE_CATALOG`/FTP 正式数据后会按来源字段自动出现。
- 本次没有重写 VDMOS 中的前端统计公式；规格、PAT、统计与采样仍以 TMS 服务端为准。
