# TMS 登录页与个人驾驶舱 Demo 完成报告（2026-09-01）

## 1. 结论

本轮已完成登录页视觉包装、个人驾驶舱 Demo、权限感知的快捷入口、前端路由接入和本机真实浏览器验证。当前结果可用于内部功能体验和后续业务讨论，但驾驶舱指标均为明确标记的演示数据，不能用于生产经营判断，也不代表 G3/G4 或生产上线批准。

未完成测试、用户联合测试步骤和问题反馈模板见：

- `docs/testing/TMS_User_Joint_Test_Checklist_2026-09-01.md`

## 2. 做了什么

### 2.1 登录页

- 使用深色半导体制造主题重新设计登录页，强化 TMS、CP/FT、Canonical、版本化 Cleaner 和治理分析定位。
- 保留原有登录、账号注册、认证 API 和错误处理逻辑，没有绕开或放宽安全校验。
- 保留“权限由管理员审批”和关键操作审计提示。
- 在启用配置认证的本机环境中验证登录页和注册弹窗可打开。

### 2.2 个人驾驶舱 Demo

- 新增 `/dashboard`，作为具有 `DATASET_READ` 权限用户的默认首页。
- 增加 Demo KPI、近 7 天制造质量脉冲、数据链路就绪度、今日关注和固定 CP/FT 快捷入口。
- 页面持续显示“演示数据 · 未连接生产”，避免把硬编码示意值误认为真实结果。
- 保持工程 CP、工程 FT、量产 CP、量产 FT 四个固定业务入口，没有增加统一 Cleaner 或自动测试类型识别。
- 质量总览和快速分析按钮按现有权限启用；无对应权限时按钮禁用，避免只靠页面隐藏造成误导。

## 4. 还不确定、不能关闭的事项

- KPI 名称、业务公式、时间范围、数据刷新频率、Owner 和异常阈值尚未完成业务签字。
- 不同角色应看到哪些卡片、工厂和经营指标，尚需权限 UAT。
- 电基 FT 的真实右侧新增参数 Golden、PASS/FAIL/Bin 口径、更多 M08M15 变体和目标环境容量测试仍未完成。
- 前端全量回归中已有 7 个超时项目尚未在稳定 CI 和人工联合测试中关闭。
- 登录/RBAC、Owner 隔离、目标 TEST、HTTPS、安全、备份恢复、容量和 CANARY 均属于开放门禁。

上述事项的逐项编号和完成条件以联合测试清单为准。

## 5. 打开方法

本机免登录功能测试：

1. 打开 `F:\CP-FT数据分析`。
2. 双击 `启动TMS测试环境.bat`。
3. 等待出现 `TMS local test environment is ready`。
4. 浏览器访问 `http://127.0.0.1:5173/`。
5. 测试后双击 `停止TMS测试环境.bat`。

真实登录页测试：

```powershell
Set-Location -LiteralPath 'F:\CP-FT数据分析'
.\scripts\windows\start_tms_local_test.ps1 -UseConfiguredAuthentication
```

本机免登录只用于功能测试，不能作为登录、权限或生产上线验收证据。
