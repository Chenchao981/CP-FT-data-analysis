# TMS CP/FT 可见图表入口完成报告

日期：2026-09-03

## 1. 问题

上一阶段的完整分析图表位于清洗结果行右侧的“数据分析”入口。CP/FT 页面默认显示原始文件记录，且入口使用普通文字链接，用户进入 `/cp` 或 `/ft` 后不能直接看到图表，功能发现路径不合格。

## 2. 已完成

- CP 与 FT 首页直接展示“最近清洗结果图表”，不需要先切换到清洗结果表。
- 图表展示当前查询最近 12 条正式结果的测试数量柱状图和已知良率折线图。
- 缺少 PASS/FAIL 事实时良率保持空值，不按 0% 展示；测试数量仍正常显示。
- 页面标题区新增“查看最新图表”，图表卡新增“打开最新完整图表”。
- 清洗结果每行的“数据分析”文字链接改为醒目的“查看图表”按钮。
- 点击入口进入该 Dataset 的完整分析页，可继续使用分析总览、参数图表、质量管控、报告与数据；CP 另外显示晶圆空间。
- 首页图表按需加载，避免把 ECharts 主包并入初始页面代码。

## 3. 验证

- 前端 Stage 数据工作台定向测试通过。
- 前端 TypeScript 检查和生产构建通过。
- 浏览器实测 `/ft`：首页可见 FT 最近清洗结果图表和两个完整图表入口。
- 浏览器点击“打开最新完整图表”：成功进入 Dataset #117 / V1 的 FT 分析页。
- FT 完整分析页显示分析总览、参数图表、质量管控、报告与数据，不显示 CP 专属晶圆空间。

## 4. 边界

- 首页图表是跨最近清洗结果的快速概览，不替代 Dataset 完整分析。
- 本次未修改清洗、PASS/FAIL、良率、PAT 或其他统计算法。
- 验证环境为本机开发环境，不等同于目标服务器生产验收。
