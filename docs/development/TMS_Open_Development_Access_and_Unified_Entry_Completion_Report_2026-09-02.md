# TMS 开发期开放权限与统一入口完成报告（2026-09-02）

## 做了什么

- `SYSTEM_ADMIN`、`DATA_DOMAIN_ADMIN` 获得全部 PERSONAL/DOMAIN 数据查看和操作能力。
- 创建并验证开发账号 `admin` 和 `domain_admin`；密码仅写入数据库哈希，未写入源码或文档。
- 新增可重复执行的开发管理员初始化脚本。
- 侧栏和个人驾驶舱由四个工程/量产入口合并为“CP 数据”“FT 数据”。
- CP/FT 列表可跨 `ENGINEERING`、`PRODUCTION` 合并查询，旧 URL 自动跳转。
- 上传页面不再要求用户选择工程/量产，工厂选择改为“选择解析工具”。
- 安全需求集中记录为延期清单，不作为当前功能门槛。

## 已验证

- 管理员登录：`admin / SYSTEM_ADMIN`、`domain_admin / DATA_DOMAIN_ADMIN` 均成功。
- 两个管理员均识别为全数据角色，并可列出当前 6 个有效数据域。
- 后端权限、统一列表与数据操作回归：112 passed。
- 前端统一入口与个人驾驶舱：28 passed。
- 个人快速分析与 Local Agent 主路径：28 passed。
- 前端生产构建：通过。

## 确定的边界

- 普通用户仍默认只操作本人 PERSONAL 数据，授权域按有效授权读取。
- 管理员全数据能力是开发期明确策略，不需要额外数据域授权。
- 工程/量产和工厂不是权限条件。

## 尚未完成或存在的限制

- SAP 量产单/工厂订单接口尚未接入，无法完成真实工程/量产判定。
- 统一入口的新上传目前以 `ENGINEERING` 写入既有必填字段，仅是技术占位。
- FTP 同根目录与多解析工具的最终 Source Catalog 配置仍需结合实际服务器目录验收。
- PDF 导出相关测试在系统 Anaconda 环境缺少渲染依赖；项目环境的本轮权限测试未受影响。
