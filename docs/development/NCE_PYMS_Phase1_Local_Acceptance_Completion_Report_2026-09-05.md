## 二、本轮发现并修复的验收阻塞问题

### 1. SQL Server 2014 保留字冲突

正式数据授权查询把 `system_user` 用作表别名，在 SQL Server 2014 中会触发语法错误。已改为非保留字别名，并增加回归检查。

### 2. 正式 FT 上传可能误选个人 PAT 工具包

原逻辑仅按“阶段 + 厂家”选择最新发布包；当同一厂家同时存在正式 Cleaner 和个人 PAT 包时，正式上传可能选中 PAT 包并失败。现已按每个 CP/FT 厂家的正式 Cleaner、Adapter、输入合同和输出合同精确选包，正式链路不会再混入个人工具包。

### 3. 普通用户正式任务授权 SQL 括号不平衡

普通用户创建正式任务时，批次访问范围 SQL 多一个右括号，SQL Server 无法预编译。已修复并在 SQL Server 2014 实库执行通过。

### 4. 参数分析稳定性验收误报

SQL 浮点聚合在重复执行时可能出现约 `1e-13` 的末位差异，原验收程序会误判为结果漂移。现按既定 `1e-9` 独立对账精度计算稳定摘要；真实数量级变化仍会失败关闭。
