## 一、结论与依据

现有项目已经具备正式 CP/FT 入库、个人分析工具、基础统计与图表、权限和追溯能力。本次复审发现两个会直接阻断报告交付的问题：一键启动遗漏独立报告 Worker，以及 Worker 真实权限查询的 SQL 括号错误。两项已修复，并通过实际 SQL Server 队列生成、下载 8 份 CP/FT 报告验证。前端补齐报告状态刷新、失败重试和驾驶舱直接分析入口。

本轮开发修复与自动测试已完成；整个产品路线图尚未全部完成。登录后浏览器全流程、业务批准规则、员工电脑和目标环境验收仍有明确缺口。

## 三、本轮完成的开发

### 1. 报告运行链

- 本地启动补入独立分析报告 Worker；独立记录进程、就绪文件、停止文件和日志。四项全部就绪，并确认数据库、服务器、Schema 一致后才返回 `all_ready=true`。
- 报告 Worker 接收预期数据库身份，在领取任务前拒绝错库、错服务器和错 Schema；退出或失败后移除就绪标记。相同控制逻辑由两个 Worker 共用。
- 停止时等待当前报告完成，再退出；超过等待时间保留进程和状态供后续处理。实际验证了四进程正常停止、重启，以及补启缺失报告 Worker。
- 生产报告 Worker 包装器支持预期数据库身份及独立就绪/停止路径。此处仅验证包装器行为，未进行生产任务注册。
- 修复真实报告权限谓词多出的右括号。新增 24 组可执行权限谓词测试，覆盖所有者、非所有者、管理员、停用账号、有效/撤销/到期域授权及非 Current/未发布版本；SQL Server 锁提示仍通过真实报告链验证。

### 2. 前端与分析错误反馈

- 报告处于排队/生成中时每 3 秒更新结果信息；终态和错误停止轮询，刷新按钮同时刷新列表和结果。
- 相同请求在提交失败后重试继续使用同一幂等键，修改请求内容后使用新键，避免修改后仍命中旧请求冲突。
- 驾驶舱最近正式数据提供“查看分析”；页面导航正确拆分路径和查询参数，不再将含参数的完整地址当作页面名称。
- CP/FT 混选、非 Current 版本、CP 规格不一致及参数缺失/身份冲突返回可操作的中文说明，保留原有拒绝条件。
- 报告模板、数据范围和文件格式使用中文标签；更新前后端说明中的旧入口、旧物理事实和三进程描述。
- 将实际灰度上传目录与分析报告目录加入忽略规则，避免原始业务文件及生成的 HTML/PDF 随源码提交。

本轮已在内置浏览器打开本地页面，确认登录页可用；当前没有可用的已登录会话，登录后“驾驶舱→正式分析→报告→下载”的整段浏览器交互尚未验收。导航、轮询、重试和下载交互已由前端组件测试覆盖，但仍需普通用户实际登录后走完整流程。

## 五、做得好的与不足

- 有效之处：把启动状态、实际队列处理、下载校验和事实不变连起来验证，发现了原有大量单元测试未覆盖的真实 SQL 故障；修复后新增可执行谓词测试，并实跑 SQL Server 报告。
- 不足：原测试对部分 SQL 采用模拟或字符串断言，未暴露语法错误；今后涉及权限和队列的 SQL 修改应保留执行型回归及实库冒烟入口。
- 当前不确定项：代表数据和模板通过不表示所有厂家、规则、图表模板、大数据量和用户路径均已验收；浏览器登录、跨机部署和生产运行必须单列证据。
