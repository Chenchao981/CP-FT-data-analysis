# NCE PYMS 架构与可用性优化执行单

日期：2026-09-05。用户已授权完成六项优化；本单继承现行产品路线图及 9 月 4 日正式包、延期事项决定，替代旧交接中的待开发清单。

## 目标及验收

1. CP/FT 独立阶段合同与身份校验；共享任务、来源和参数语义。先在现有存储边界落实合同，物理分表须有数量对账、回滚和查询兼容方案，不以新建空表冒充迁移完成。
2. 参数分析显示数据不足、规格和规则不适用的具体原因，保留现有批准算法；不猜测业务规则。
3. 常用正式厂家的能力登记和管理查看入口；严格匹配用途、格式及输出合同，继续直接使用外部正式包。
4. 员工电脑入口说明、可复现安装和连接诊断；无第二台可控电脑时明确现场验收边界。
5. 正式及个人结果共用解释组件，明确数量、方法、数据归属和历史复用。
6. 稳定的前端回归配置、真实样本性能记录及完成报告。

## 执行顺序

合同与能力目录 → 页面接入及结果解释 → 本机接入诊断 → 定向及全量回归 → 真实样本验证 → 更新现状入口和交接 → 提交推送。

## 范围约束

- CP、FT 分别调用成熟 Cleaner，不重写厂商解析或统计。
- 不扩展 FTP 定时采集、SAP、异常工单或 AI。
- 不改变历史 Dataset 或原始样本。
- 个人分析结果不进入正式 KPI。
- 需要业务批准的规格/规则及第二台电脑、目标服务器验收必须如实列为外部验收项。
