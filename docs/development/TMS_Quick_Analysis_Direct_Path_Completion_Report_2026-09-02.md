# TMS 快速分析直连目录重构完成报告（2026-09-02）

## 做了什么

- 快速分析前台取消 Local Agent、8765 端口、配对 Token 和独立工具安装等用户操作。
- 新增“本机 / NAS 路径”：输入当前 TMS 主机可访问的本地盘符、映射盘符或 UNC 目录，选择 CP/FT 厂商工具，先递归预览工具需要的源文件，再创建个人 PAT 任务。
- FT Worker 直接调用 Cleaner Registry 中已发布的杰群低内存 PAT 包；没有复制或重写 FT PAT 算法。
- CP 已接入华虹、积塔、立昂微、国宇四个入口。Worker 先调用所选厂商的已发布 CP Cleaner，再在同一个版本化 `app.pyz` 中运行 CP PAT；TMS 不实现厂商解析和 CP PAT 公式。
- CP 清洗中间 CSV 只位于任务 Workspace，PAT 完成后删除；系统只保留 PAT Excel、摘要和源目录 Manifest，不写入正式 Canonical。
- 预览、排队前和计算完成前都使用同一文件数、大小、修改时间 Manifest。范围变化时停止任务并要求重新预览。
- 保留“已配置服务器”作为共享、定时和反复使用的 FTP/NAS 主入口，结果权限继承数据域。
- 新增“临时 FTP 预览”，支持 FTP/显式 FTPS 地址、端口、账号、密码和远程目录；密码只用于本次请求，不写入配置或响应。
- NAS 已由直连目录支持当前 Windows 账号可访问的映射盘符或 UNC；需要独立账号的 NAS 连接仍由后台配置承担。
- 数据库升级至 `sql2014_0025`，Quick Analysis 隔离区允许 CP/FT 两种会话；正式 `test.*` Canonical 结构不变。
- Quick Analysis 列表读取遇到 SQL Server 1205 死锁牺牲时最多短重试两次，避免 Worker 完成写入瞬间的偶发页面 500；其他数据库错误仍原样失败。

## 确定的权限行为

- 本机/UNC 直连任务是 `PERSONAL`，默认只有发起人以及开发期全数据管理员可见。
- 已配置服务器任务是 `DOMAIN`，依赖当前有效数据域授权。
- 临时 FTP 当前只返回目录预览，不生成共享数据权限；需要计算时配置为服务器数据源。
- 工程/量产和工厂不是本功能的数据权限条件。
