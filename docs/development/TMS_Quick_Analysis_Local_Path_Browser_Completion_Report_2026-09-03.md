# TMS 快速分析本机路径浏览改造完成报告（2026-09-03）

## 目标

将“快速分析 / 本机、NAS 路径”改造成与现有 CP 工具一致的直接路径使用方式：用户可以浏览当前 TMS 运行电脑能够访问的本地盘、映射盘或 UNC 路径，选择目录、单个源文件或工具支持的压缩包，先确认解析范围，再调用已发布的 CP/FT 工具执行 PAT。源文件不经浏览器上传，也不写入正式 Canonical 明细。

## 已完成

- 新增“浏览路径”入口和可导航路径窗口，支持盘符入口、上一级、地址跳转、双击进入目录。
- 目录中只显示当前分析工具认可的子目录、源文件和压缩包，并显示类型和文件大小。
- 支持选择当前文件夹或单个源文件；FT 单文件会在任务临时目录内用硬链接（不可用时复制）适配既有目录型 PAT 接口，任务结束自动清理。
- CP 压缩包格式按既有 Cleaner 能力开放：华虹支持 ZIP/7z，积塔、立昂微、国宇支持 ZIP。
- 华虹原始 TXT 必须选择所在目录，以保留产品/批次目录信息；界面会禁用单 TXT 选择并给出提示，ZIP/7z 可直接选择。
- 预览结果增加“文件夹/单个文件”“压缩包数量”“解析来源”和实际待解析文件列表；总数全量统计，页面最多展示前 100 个文件名。
- 后台 Manifest、任务创建和 Worker 执行统一支持文件或目录，并在开始和结束时继续校验源数据是否变化。

## 使用边界

- 当前实现按已确认的部署方式工作：TMS 后端运行在用户电脑或能直接访问数据路径的服务器上；页面展示的是该后端进程账号可访问的路径。
- 映射盘和 UNC 目录是否可见，取决于运行 TMS 的 Windows 账号本身是否已经具有访问权限。
- 压缩包能力严格复用现有 CP Cleaner；FT 当前开放既有工具原生支持的 CSV/XLS/XLSX 源文件和目录，不额外发明新的压缩包解析规则。
