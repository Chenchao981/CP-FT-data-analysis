# TMS 用户联合测试清单（2026-09-01）

## 1. 怎么理解本清单

- **未完成测试**：当前没有足够真实样本、目标环境或业务签字，不能关闭。
- **自动化超时**：程序没有出现断言错误，但测试在规定时间内没有结束，需要人工复测并在稳定 CI 重跑。
- **已通过、建议复测**：开发侧已有自动化或浏览器证据，邀请业务用户从实际操作角度再次确认。

发现问题后请记录：清单编号、页面入口、操作步骤、期望结果、实际结果、Batch/Job/Dataset 编号、截图时间。不要发送密码、原始客户数据或数据库连接信息。

## 3. 前端全量自动化中尚未关闭的 7 个超时项

这些用例在低并发全量运行中超时，没有出现业务断言不一致。本次电基定向测试、生产构建和浏览器操作均通过，但以下项目仍需要人工复测和稳定 CI 重跑。

| 编号 | 自动化超时功能 | 建议人工复测 |
|---|---|---|
| FE-01 | 新建明确的 DRAFT 分析规则 | 质量管理摘要 → 规则管理；不填 Golden/规则参数时，系统不得静默补值，状态应保持 DRAFT。 |
| FE-02 | 最新 Cleaner 非变更导出确认 | 历史正式数据 → 最新 Cleaner 导出；未勾选明确确认前不得创建任务，导出后不得改变 Current/Dataset Version。 |
| FE-03 | 参数图共享 Y 轴范围 | 参数分析设置 Y 轴上下界，再清除；请求数据范围不能被改变，图表范围应恢复自动。 |
| FE-04 | 参数分析错误与显式重试 | 模拟服务暂不可用时应显示结构化错误；只有点击“重试”才重新请求，页面不能后台无限重试。 |
| FE-05 | 参数关系 NO_SPEC | 选择没有正式规格的参数关系；页面应显示 NO_SPEC，不能绘制虚假的 Program Limit。 |
| FE-06 | 参数关系规则批准门禁 | 未批准相关性规则时应显示审批门禁，前端不能自行计算替代结果。 |
| FE-07 | Source Catalog 提交失败后的确认清理 | 目录预览并确认后，让目录 Manifest 变化或提交失败；旧确认必须清除，重新提交前必须刷新 Manifest。 |

## 6. 打开 TMS 前端

### 最简单方式（本机功能测试，免登录）

1. 打开 `F:\CP-FT数据分析`。
2. 双击 `启动TMS测试环境.bat`。
3. 等待窗口出现 `TMS local test environment is ready`。
4. 浏览器会自动打开 `http://127.0.0.1:5173/`。
5. 双击 `查看TMS测试环境状态.bat`，确认 `all_ready/api_ready/worker_ready/frontend_ready` 都是 `True`。

测试结束后双击 `停止TMS测试环境.bat`。默认入口使用本机免登录管理员，仅用于功能测试，不能用它证明登录/RBAC 已验收。

### 测试真实登录页

先停止免登录环境，再在 PowerShell 中执行：

```powershell
Set-Location -LiteralPath 'F:\CP-FT数据分析'
.\scripts\windows\start_tms_local_test.ps1 -UseConfiguredAuthentication
```

浏览器打开 `http://127.0.0.1:5173/` 后应显示新版登录页。测试账号必须由管理员预先启用并分配角色；不要在聊天或截图中提供密码。
